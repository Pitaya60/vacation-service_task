## Решения

### D1 — Запуск без Docker (дата сессии: 2026-10-10)
- **Проблема:** Docker Desktop на машине не запустился; первый план (Node + Docker) делал запуск зависимым от него.
- **Альтернативы:** починить Docker; ставить PostgreSQL вручную; встроенный PostgreSQL через pip.
- **Решение:** `pgserver` (pip-пакет с настоящим PostgreSQL 16) поднимается сам при старте backend; для внешней БД — `DATABASE_URL`.
- **Компромисс:** данные в `.pgdata/`, нельзя запускать от администратора Windows; для production — обычный Postgres.
- **Проверка:** запуск и 27 тестов на этом Postgres прошли в сессии Claude (Linux). На Windows пользователя — не проверено.

### D2 — Python/FastAPI вместо Node
- Требование пользователя. FastAPI даёт валидацию запросов и `/docs`; SQL пишется напрямую, без ORM: нужны `on conflict do nothing`, пересечение интервалов, `pg_notify`.

### D3 — Остаток не хранится, а считается функцией `accrued()`
- Смена даты выхода пересчитывает всё без миграций данных. Проверено тестом `test_hire_date_change_recalculates`.

### D4 — «Ровно одно» уведомление держит БД
- `unique(type, vacation_id, recipient_id)` + `on conflict do nothing`. Проверено: гонка двух согласований и двойной вызов `remind()` дают по одному уведомлению.

### D5 — SSE поверх Postgres LISTEN/NOTIFY
- Нужен только поток сервер→клиент; NOTIFY работает и при нескольких процессах. Проверено e2e-тестом на две сессии.

### D6 — Согласование атомарно
- `update ... where status='pending' returning` — второй одновременный запрос получает 409.

### D7 — Запуск через start.bat, Python только 3.10–3.12
- **Проблема:** у пользователя страницы не запустились. Вероятные причины: для Python 3.13/3.14 нет колеса `pgserver` под Windows (проверено `pip download --platform win_amd64`), `.ps1` и `npm` блокирует политика выполнения PowerShell.
- **Решение:** `start.bat` (cmd, без политик) ищет подходящий Python (`py -3.12/3.11/3.10`), проверяет Node, оставляет окна открытыми при ошибке; frontend показывает понятную ошибку, если backend недоступен.
- **Статус:** причина у пользователя не подтверждена (текст ошибки не получен); на его Windows не проверено.

### D8 — Календарь месячной сеткой
- Строки — сотрудники, столбцы — дни, цвет по статусу; перерисовывается по SSE. Проверено сборкой, визуально не смотрено.

### D9 — Поддержка Python 3.13/3.14: переход на `pixeltable-pgserver`
- **Проблема:** у разработчика Python 3.14.2; оригинальный `pgserver` не имеет колёс для 3.13+ под Windows (D7).
- **Альтернативы:** ставить Python 3.12; ставить PostgreSQL вручную; форк `pixeltable-pgserver` (модуль `pixeltable_pgserver`, тот же API `get_server`).
- **Решение:** форк как единственная зависимость; в `db.py` запасной импорт оригинального `pgserver`.
- **Проверка:** `pip download --platform win_amd64` нашёл колёса форка и остальных пакетов для Python 3.9–3.14; 27 тестов прошли на форке (Linux, Python 3.12). На самом Python 3.14 и на Windows не запускалось.

## Problems and resolutions

### P1 — Docker не стартует
- **Observed:** `error during connect ... dockerDesktopLinuxEngine: The system cannot find the file specified`.
- **Root cause:** предположительно Docker Desktop не запущен (не подтверждено).
- **Resolution:** отказ от Docker, встроенный PostgreSQL (D1). **Verification:** тесты в среде Claude; на компьютере разработчика — не проверено.

### P2 — страницы не открываются после запуска
- **Observed:** текст ошибки не получен. **Root cause:** не подтверждена; кандидаты — Python 3.13+, политика PowerShell.
- **Resolution:** `start.bat` с проверкой версии Python (D7). **Verification:** не проверено на компьютере разработчика.

### P3 — файлы не создались при генерации (ошибка ИИ)
- **Root cause:** `{a,b}` не раскрывается в `sh`. **Resolution:** папки созданы явно, файлы записаны повторно, лишняя папка удалена. **Verification:** список файлов архива.

### P4 — `npm install` в папке результатов
- **Observed:** ошибка ввода-вывода при установке и удалении `node_modules`. **Resolution:** сборка во временной папке; `node_modules` исключён из архива. **Verification:** `vite build` успешен.
